# bytesbay/tap

Homebrew casks by [@bytesbay](https://github.com/bytesbay).

```sh
brew install --cask bytesbay/tap/pi-gpui
```

| Cask | What |
|---|---|
| `pi-gpui` | [Pi GPUI](https://github.com/bytesbay/pi-gpui), a native Mac app for the pi coding agent, written in Rust with GPUI |

The app updates itself. A workflow points the cask at each new release within a few hours.
